# Панель управления: текущий статус и ближайший путь

Обновлено: 27 июля 2026.

## Текущий статус

Админка переведена в единый боевой режим:

```txt
/admin
  -> защищенный Cloudflare Access интерфейс
  -> /api/admin/*
  -> D1 yakov_archive
  -> R2 yakov-public-assets
```

Старой развилки между локальной админкой и `/admin/ingest` больше нет.
`/admin/ingest` только перенаправляет в `/admin/albums`. `localStorage` и IndexedDB не
являются источником архивных данных.

Локально полностью проверены:

- создание и редактирование альбомов;
- последовательная загрузка JPEG;
- три реальные версии `thumb`, `display`, `expanded`;
- очистка публичных metadata;
- порядок и обратный порядок пленки;
- обложки landscape/square/portrait;
- теги альбома и прямые теги фотографии;
- одна фотография в нескольких альбомах без копирования файлов;
- создание и порядок сетов;
- hide/publish;
- Bin, restore и permanent purge;
- album-level Download;
- публичные страницы из D1.

## Как загружать новый альбом

1. Открыть `https://yakov.shmol.cc/admin/albums`.
2. Создать альбом; он по умолчанию `draft`.
3. Выбрать или перетащить пакет JPEG.
4. Дождаться, пока очередь покажет сохранение в `D1 + R2`.
5. Проверить порядок; для обратной нумерации пленки выбрать `Last to first`.
6. Назначить обложки и теги.
7. При необходимости добавить альбом в один или несколько Sets.
8. Включить `Allow JPEG download`, только если посетителям нужна кнопка Download.
9. Перевести фотографии и альбом в `published`.
10. Опубликовать Set, если альбом должен появиться на главной.

Опубликованный альбом без опубликованного Set доступен в `/albums`, но не появляется на
главной. Draft/review/hidden/Bin не видны посетителям.

## JPEG Pipeline

```txt
вход: JPEG до 20 MiB
thumb: до 640 px, цель <= 300 KB
display: до 2000 px, цель около 1 MB
expanded: очищенный загруженный JPEG
```

Обычный просмотр использует `display`. Кнопка `+` подгружает `expanded`. Download
использует тот же `expanded`, поэтому файл в R2 не дублируется.

Большие 20-50 MB исходники, RAW/RAF/TIFF остаются в Google Drive. Их будущая привязка
как private `master` предусмотрена моделью, но не входит в текущий upload.

проверен, а ранее загруженный smoke-альбом виден в едином Albums workspace со всеми

Следующие улучшения делаются по реальному использованию: bulk metadata, Google Drive
master links, автоматическая обработка в Queue и расширенный поиск.
